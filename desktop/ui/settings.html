Settings

The coding agents braid can use, which one runs by default, and which model each uses. Switch off any you do not want braid to use. These apply to new runs in every window.

Runs already in progress keep the agent and model they started with. Type or pick a model; suggestions come from your installed program, or the provider's live list once a key is saved. Leave it empty for the CLI's own default. Other OpenAI-compatible providers and local models are planned.
